# 大模型面试100问 - 核心知识点梳理

## 📚 项目简介

本项目是对《大模型面试100问》PDF文档的系统性梳理，涵盖了大模型领域的核心技术知识点，包括模型架构、训练技术、推理优化、强化学习等多个方面。

## 📖 内容概览

### 一、参数高效微调技术 (PEFT)
- **LoRA**: 低秩矩阵分解，减少微调参数量
- **AdaLoRA**: 自适应调整低秩值
- **QLoRA**: 结合4-bit量化和LoRA
- **Adapter技术**: 插入小型可训练模块
- **Prefix-tuning/P-tuning/Prompt-tuning**: 提示学习方法

### 二、训练优化技术
- 混合精度训练原理与流程
- float16/bfloat16/float32的选择
- 溢出问题的解决方案

### 三、预训练任务
- CLM（因果语言建模）
- MLM（掩码语言建模）
- GLM自回归空白填充

### 四、模型架构
- Transformer核心组件
- Encoder-only/Decoder-only/Encoder-Decoder对比
- 为何Decoder-only成为主流

### 五、注意力机制优化
- 多头注意力机制原理
- Q、K、V的设计意义
- Scaled Dot-Product原因
- KV Cache与GQA

### 六、位置编码
- 绝对位置编码 vs RoPE（旋转位置编码）

### 七、归一化与激活函数
- LayerNorm vs BatchNorm vs RMSNorm
- ReLU vs SwiGLU

### 八、分词技术
- BPE、WordPiece、BBPE原理对比

### 九、主流模型架构
- BERT、LLaMA、Qwen、LLaMA 3.1的特点与创新

### 十、推理加速技术
- FlashAttention、vLLM原理

### 十一、分布式训练
- ZeRO系列（ZeRO-1/2/3）
- 数据并行、张量并行、流水线并行

### 十二、强化学习
- PPO、DPO算法原理与对比

### 十三、MoE（混合专家模型）
- 核心架构与Dense模型对比

### 十四、代码实现
- Self-Attention、Multi-Head Attention的PyTorch实现

## 🎯 面试重点

### 必须掌握的核心概念
1. **LoRA原理与初始化**
2. **Transformer架构细节**
3. **注意力机制(Q/K/V)**
4. **位置编码(RoPE)**
5. **归一化技术(LayerNorm/RMSNorm)**
6. **混合精度训练**
7. **PPO/DPO算法**
8. **Self-Attention代码实现**

### 常见面试题型
- **原理阐述题**: 解释某技术的核心原理
- **对比分析题**: 比较不同方法的优缺点
- **代码实现题**: 手撕核心算法
- **场景应用题**: 如何选择合适的技术方案
