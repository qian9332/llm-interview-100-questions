## 📖 内容概览

### 一、参数高效微调技术 (PEFT)
- **LoRA**: 低秩矩阵分解，减少微调参数量
  - 数学公式：$\Delta W = B \cdot A$
  - 初始化策略：B矩阵初始化为0
  - 参数压缩比：256倍
- **AdaLoRA**: 自适应调整低秩值
- **QLoRA**: 结合4-bit量化和LoRA
- **Adapter技术**: 插入小型可训练模块
- **Prefix-tuning/P-tuning/Prompt-tuning**: 提示学习方法

### 二、训练优化技术
- 混合精度训练原理与流程
- float16/bfloat16/float32的选择
- 损失缩放技术
- 梯度问题解决方案

### 三、预训练任务
- **CLM（因果语言建模）**: 自回归生成
- **MLM（掩码语言建模）**: 双向理解
- **GLM自回归空白填充**: 结合两者优势

### 四、模型架构
- Transformer核心组件详解
- Encoder-only/Decoder-only/Encoder-Decoder对比
- 为何Decoder-only成为主流

### 五、注意力机制优化
- 多头注意力机制原理与实现
- Q、K、V的设计意义
- Scaled Dot-Product原因
- KV Cache与GQA

### 六、位置编码
- 绝对位置编码 vs RoPE（旋转位置编码）
- RoPE数学推导与实现

### 七、归一化与激活函数
- LayerNorm vs BatchNorm vs RMSNorm
- ReLU vs GELU vs SwiGLU

### 八、分词技术
- BPE、WordPiece、BBPE原理对比
- 完整算法实现

### 九、主流模型架构
- **BERT**: Encoder-only架构
- **LLaMA**: RMS Pre-Norm + SwiGLU + RoPE
- **Qwen**: 多语言支持 + 长上下文
- **LLaMA 3.1**: 三阶段预训练

### 十、推理加速技术
- FlashAttention原理与实现
- vLLM的PagedAttention

### 十一、分布式训练
- ZeRO系列（ZeRO-1/2/3）
- 数据并行、张量并行、流水线并行

### 十二、强化学习
- PPO算法原理与公式
- DPO算法与PPO对比

### 十三、MoE（混合专家模型）
- 核心架构与实现
- 与Dense模型对比

### 十四、代码实现
- Self-Attention完整实现
- Transformer Block实现
- 包含详细注释

## 🎯 面试重点

1. **LoRA原理与初始化**
   - 为什么B初始化为0？
   - 参数量计算
   - 优势分析

2. **Transformer架构细节**
   - 多头注意力机制
   - 前馈神经网络
   - 残差连接

3. **注意力机制(Q/K/V)**
   - 三个矩阵的作用
   - 为什么需要三个矩阵
   - Scaled原因

4. **位置编码(RoPE)**
   - 数学推导
   - 相对位置特性
   - 代码实现

5. **归一化技术(LayerNorm/RMSNorm)**
   - 公式对比
   - 适用场景

6. **混合精度训练**
   - FP32/FP16/BF16选择
   - 损失缩放

7. **PPO/DPO算法**
   - 核心公式
   - 算法对比

8. **Self-Attention代码实现**
   - 完整实现
   - 维度变化

### 常见面试题型
